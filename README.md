# We The Free Organiser Dashboard

An attendance app for We The Free (WTF) city teams, starting with Sydney.

Organisers tick off who turns up to each event, and can see who has been to what: person histories, event headcounts, regulars and lapsed attendees, monthly totals and outreach milestones.

## Status

Phase 1 (check-in core) is being built.

## Stack

- Next.js (web app, mobile-first)
- Supabase (database and logins)
- Vercel (hosting and the daily event import)
