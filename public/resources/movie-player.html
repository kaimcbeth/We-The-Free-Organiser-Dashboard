SETUP
To get back to setup, press and hold the heading for 2 seconds.
  1. Put this player file and the films in the same folder on this laptop (or on a USB stick). With language folders, put it in the folder that holds them.
  2. Click Choose films and select the films in that folder. Films in language folders (French, Arabic…)? Click Choose a folder and pick the folder that holds them all: each film gets its language from its folder.
  3. That's it. Next time, just open this file and the menu will be here.

Works with no internet. MP4 films play on every laptop, Windows or Mac.
Need the films? Download them from the videos folder on Google Drive.
