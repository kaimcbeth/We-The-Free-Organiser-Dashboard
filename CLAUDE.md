## How the app works (key ideas)

- Roles: God, Regional Support Lead, Organiser, Core Team, member. One role per account, except a God account can also be a community's organiser and a region's RSL (`organisers.organiser_team_id` / `lead_region_id`; Kai: Sydney + Oceania). God can "View as" any role, including "New Organiser (existing/new community)"; the new-community view uses a Practice Community that resets on every view change.
- Actions (`task_kinds` → `tasks`): generated by pg_cron every 10 min around events (anchor/appear/due hours), weekly/monthly/quarterly, per newcomer, month end, follow-ups. Teams switch kinds on/off (`team_task_kinds`).
- Events import hourly from each team's activism.wtf calendar. Organiser Hangouts (activism.wtf/hangouts/…) import hourly from the site's sitemap (no list page or feed) into `hangouts`; "For organizers in Oceania + Japan" is matched to regions and countries (trigger). Shown as listings only (Events Upcoming + calendar, via `team_hangouts`), never in `events`. Region-wide actions use `tasks.region_id` (team_id null), shown by `RegionActions` on Actions. RLS everywhere; anything cross-cutting goes through `security definer` functions that check the caller.
- The organiser's community setup checklist pops up after the tour. Volunteers RSVP (Going/Maybe/Can't), get a day-before reminder, see their impact, and use the Outreach guide (questions only now) between street conversations.

## Movie player (30 Oct 2026)

- Offline single-file player for Movie Challenge laptops (mostly Windows, also Mac): `public/resources/movie-player.html` (plain JS, no build). Kept in the same folder as the MP4s; "Choose films" once per laptop, remembered in localStorage (`wtf-movie-player-v2`); later plays use the relative file name. Tiles = films (Standard, Children's, Vegetarian, Halal); a tile can hold several versions (A/B test), picked at random keeping plays even per laptop. Files named "X A.mp4"/"X B.mp4" auto-group into tile "X". Edit menu: rename, reorder, remove, "Make it a version of…", "Own tile".
- After each film ends (survey fades in over 5 s, `.fade-in`; taps ignored for the first 1.5 s, Kai 31 Oct): "How much did viewing this video impact you?" 0–10 (Kai's wording) + Skip (auto-skip after 2 min). Answers in localStorage (`wtf-movie-player-answers-v1`) with film, version (file name), laptop (random "Laptop XXXX"). Results panel on the player: per film, Send results, Save results file (CSV).
- `/resources/movie-player/download` injects `{url, key, token, community}` at `/*WTF_CONFIG*/null` (team's `teams.player_token` via `team_player_token`). The player posts to `submit_film_surveys(p_token, p_rows)` (anon, security definer; `client_id` unique so resends are harmless) after each answer, on `online`, and every 20 s. Table `film_survey_responses` (organisers read via RLS).
- `/resources/movie-player` page: download, steps (Drive videos folder link), "Live at the event" (`live-players.tsx`), live "Watched today" counter (polls every 10 s; per film, per laptop), "Which film has the most impact" (all-time averages; By language; A/B per language; "too early" under 30 answers), and "See all N answers" with tick + delete (RLS delete policy, 0145). Card 🎬 Movie player in Resources (not Core Team).
- Viewers: tapping a tile asks "How many people are watching?" (1–5 + More stepper, no cap); the question then repeats per person ("Person 2 of 3"), one answer row each. Hover highlight suppressed until the mouse moves (class `fresh`).
- Languages (0146): file name suffix " - Mandarin" etc. (`LANGS` table in the player; aliases). Language buttons on the menu when >1 language; tiles filtered by language; A/B within a language. Mandarin has UI + survey + tile-name translations (`ui`, `films`); other languages fall back to English screens. Answers carry `language`.
- Live screen (0147): player reports to `set_player_status` (token, device_id (random, kept), laptop name (asked on a "Which laptop is this?" screen, A–D only (Kai's choice), when the player opens on a new day (`wtf-movie-player-named` = date); "Laptop: X · Change" chip top-left of the menu), state idle/playing/paused/survey, film, language, seconds_left, duration, viewers) on play/pause/seek/end and a 15 s heartbeat; server sets `ends_at`. Phone polls `live_players(team)` every 3 s (returns server `now` for clock skew), ticks locally; cards show progress bar + time, pink pulsing ring + beep/vibrate/SW notification at 10 s ("Turn on alerts" unlocks audio, asks notification permission, wake lock). Offline after 45 s silence; hidden after 30 min. "Finished" alert: when a laptop goes from survey to anything else between polls, a rising chime + vibration + notification, and the card shows "Finished · ready to chat" (pink, Kai 31 Oct; was cyan) for 60 s (`done` state, detected in `load`). `LivePlayers` lives in `src/components/live-players.tsx`: with `teamId` (organiser Movie player page) uses `live_players(team)`; without, uses `my_live_players()` (0149: members, Core Team, organisers of their own community) and shows only while laptops are running — on members' Events page (`/me`, `noIntro`: no explainer text; `withToday`: "Watched today" panel from `my_movie_today()` (0154, totals only, team timezone), fetched every ~10 s while laptops are running) and Core Team's `/attendance` (polls 20 s when empty, 3 s when running). Also on Movie Challenge event pages (organiser `/events/[id]`, Core Team `/attendance/[id]`) from 1 h before start to 1 h after end (`src/lib/live-window.ts`, title matches /movie challenge|3mmc/).
- Two copies of the player on one laptop share `device`; only the busy one reports (`wtf-movie-player-active` = {tab, at}, 40 s), so an idle copy can't flick the card to "Free" (31 Oct, after Kai hit it with two copies open; laptops need the player re-downloaded).
- Stall watchdog (31 Oct, Kai saw films stop a few seconds before the end): every 500 ms; if the film isn't advancing, wasn't paused by a person (`userPaused`, set in `toggle`) and is in its last 10 s for 2 s → `endFilm()` (survey); stalled elsewhere while not paused → one nudge (+0.1 s, play). Tested in Playwright.
- "Video not working?" (0153, Kai 31 Oct): subtle `.help-btn` bottom-left (13px, faint, no border; quieter than the tapout pill; both drop to the bottom edge when controls hide, `#player.idle`), explained on the intro screen. Click → pause, `#problem` screen ("Thanks for letting us know." + "Someone will be with you in a few seconds.", Keep watching / Start again), live state `problem` (no stop row). Live screen: yellow (amber) pulsing card "Video not working · needs a hand", urgent beep + vibrate + notification once per press. Mandarin strings added (helpBtn, introHelp, problemTitle, resume, restart).
- Stop button (0148): "Before you start" screen after the viewer count (encourages seeing it through, shows the button). During the film an always-visible pill "I'm not comfortable watching this anymore" (bottom-right, not hidden with controls). One tap: pause, solid "That's completely okay. Someone will be with you in a few seconds." screen, "Keep watching for the others" (viewers > 1; the stopper is counted as a skipped answer) or "Finish" (→ survey). Records a stop row (`stop: true` through `submit_film_surveys` → `film_stops`: film, version, language, stopped_at, duration). Live status 'stopped' + `stopped_at` → red card, urgent beep, vibration, notification. Results: "Stop pressed N times, on average at m:ss (x% through)" per film/language/version; stops in "See all" list (deletable).
